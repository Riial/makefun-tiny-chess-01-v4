A tiny chess engine in 4 KB of Python: 0x88 board, negamax alpha-beta with
quiescence, transposition table, killers, adaptive null-move pruning, check
extensions, futility and delta pruning, and a tapered PeSTO evaluation,
playing the house gauntlet under a fixed node budget.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
